# Processor inventory — מה שכחתי?

**Policy version:** `2026-09-18`  
**Operator:** Pelemotors · Contact: `noreply@mashachachti.co.il`  
**Rule:** Only processors evidenced in product/config are listed. Unknown retention or subprocessors = `UNVERIFIED` / `REQUIRES_DECISION`.

## Summary

| Processor | Role | Data categories (product) | Sharing direction | Contractual status |
|---|---|---|---|---|
| Supabase (self-hosted) | Auth, Postgres, Storage | Account, product content, recordings metadata/objects, device/push tokens | App ↔ self-hosted stack | Operator-controlled host |
| OpenAI | Agent + transcription | Chat/context payloads; audio for transcription; derived transcripts | Server → OpenAI API | Vendor ToS (`UNVERIFIED` subprocessors) |
| Resend | Auth email SMTP for Supabase | Email address; auth email content (magic link / reset) | Supabase Auth → Resend SMTP | Vendor ToS |
| Web Push (browser push services) | Reminder delivery | Push subscription endpoint + encrypted payload | Server → browser push infra | Platform terms |
| FCM (optional) | Native Android push | Device push token; notification title/body | Server → FCM when configured | Optional; vendor terms |
| APNs (optional) | Native iOS push | Device push token; notification title/body | Server → APNs when configured | Optional; vendor terms |
| Apple Sign In | Native identity | Identity token / Apple user identity fields needed for auth | App → `/api/auth/native` → Supabase | Platform auth |
| Google Sign In | Native identity | Identity token / Google user identity fields needed for auth | App → `/api/auth/native` → Supabase | Platform auth |

**Not in inventory (explicit non-use):** third-party analytics SDKs (e.g. Google Analytics). First-party telemetry only via `logMobileEvent` + `sanitizeTelemetryMetadata`.

## 1. Supabase (self-hosted)

| Field | Fact |
|---|---|
| Purpose | Authentication, Postgres application data, Storage for recordings |
| Auth surfaces | Email/password (and related auth email); native Apple/Google via `/api/auth/native` |
| Anonymous users | Not offered |
| Storage | Bucket `recordings` only (user audio objects) |
| Access control | RLS enabled on public tables; `service_role` server-side only |
| Delete behaviour | User-owned rows `ON DELETE CASCADE` from `auth.users`; `account_audit.user_id` `ON DELETE SET NULL` |
| Hosting | Operator-controlled (self-hosted), not a SaaS multi-tenant claim beyond this product’s host |

**Data examples stored:** email/account; tasks, shopping, checklists, chat, memories; recordings rows + Storage objects; device/push registration; notification records.
